# ABC-Company-Employee-Analysis
Employee dataset analysis project with preprocessing, visualizations, and insights

This project analyzes employee data from ABC Company (458 rows × 9 columns). The goal is to preprocess the dataset, perform key analytical tasks, and present findings through visualizations.
Preprocessing
Corrected the height column by replacing values with random integers between 150–180 cm.
Ensured consistency and verified distribution before analysis.

Analysis Tasks
Team Distribution → Employee count & percentage split (bar chart).
Position Segregation → Employees grouped by position (horizontal bar chart).
Age Groups → Predominant age range identified (histogram).
Salary Expenditure → Highest spending team & position (bar charts).
Age vs Salary → Correlation checked (regression plot).

Graphical Representations
Bar charts for team and salary analysis.
Horizontal bar chart for positions.
Histogram for age distribution.
Regression plot for age vs salary.

Insights
Workforce distribution highlights dominant teams and roles.
Predominant age group reflects company demographics.
Salary costs are concentrated in specific teams/positions.
Age vs salary trend shows compensation patterns.
